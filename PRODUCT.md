# Home Starter

Home Starter helps a household use its existing Home Assistant installation.
People should be able to prepare the house, scan, describe who lives there, choose
useful capabilities, review supported changes and press one clear Go action.

First visits commission a home. Returning visits lead with status, changes and
readiness; older installations retain everything and may optionally finish setup.
The administration UI extends the incumbent design in DESIGN.md: plain language,
native controls, progressive disclosure and responsive forms in Operate mode.

Discovery is evidence, not consent or verification. Plans and configuration are
distinct from working checks. Optional capabilities can be skipped. Existing
dashboards are preserved unless explicitly selected for reviewed publication.
Credentials stay in the relevant Home Assistant or service interface.

Supported automation includes household settings, selected native dashboards and
the existing Music Assistant installer. Calendar/waste checks read real events;
physical controls, playback, SIP and camera tests require supported adapters and
must remain incomplete when those adapters are absent.
