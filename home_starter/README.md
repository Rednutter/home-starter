# Home Starter

Scan your Home Assistant, pick what you want to do, and let Home Starter set
up the sensible existing component the Home Assistant way, then check it works.

Version 0.2 adds optional **Fresh Batteries** preparation and **Your home** inventory,
with explainable findings and verified device room assignment. The working **music
around the house** flow with Music Assistant remains available.
