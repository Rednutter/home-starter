# Home Starter

Scan your Home Assistant, pick what you want to do, and let Home Starter set
up the sensible existing component the Home Assistant way, then check it works.

Version 0.3 adds **Make the house usable**: people and screen requirements, native
household dashboards, saved Pin / Hide / Reorder and explicit appliance activity
today. **Fresh Batteries**, **Your home** inventory and **Music around the house**
remain available. Read [surface rules and limits](SURFACES.md).
